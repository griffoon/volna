Официальное приложение Яндекс Музыки обросло подкастами, книгами, сторис, детским разделом и рекламой Плюса. «Волна» — это то, что остаётся, если всё это убрать: Моя волна, твоя коллекция, поиск и хороший плеер. Тёмный монохром, моноширинный шрифт, один кислотный акцент (или цвет из обложки) и визуализатор, который правда слышит музыку.

> [!WARNING]
> Неофициальный проект, никак не связан с Яндексом. Работает через неофициальный API, который может сломаться в любой момент. Для полных треков нужна своя подписка Яндекс Плюс. Приложение ничего не скачивает в файлы и не обходит ограничения подписки.

## Возможности

### Моя волна
- Бесконечный поток через rotor-сессии. Волна учится на лайках, дизлайках, пропусках и прослушиваниях (`/play-audio`), как в официальном клиенте.
- Настройки волны: настроение, характер, язык. Волны по занятиям, по треку, по артисту; «продолжить последнюю волну».
- Экран как у Яндекса: дымный фон в цветах обложки, имя артиста крупно, обложка листается свайпом, дизлайк на видном месте.
- Когда треки в очереди кончаются, волна сама продолжается по последнему треку.

### Плеер
- Lossless (FLAC), MP3 320 или AAC. Бесшовные переходы с предзагрузкой, кроссфейд 0–12 с.
- 10-полосный эквалайзер с пресетами и выравнивание громкости по данным R128 от Яндекса (−14 LUFS).
- Обложка-карточка: свайп в сторону переключает трек, соседняя обложка выглядывает сбоку.
- Караоке как в Apple Music: синхронный текст с заливкой строки, тап по строке перематывает. Если у Яндекса текста нет, он берётся из [LRCLIB](https://lrclib.net).
- Таймер сна, очередь, «играть следующим», память позиции после перезапуска.
- Экран блокировки, Dynamic Island, AirPods. Лайк и дизлайк прямо с экрана блокировки.
- Ссылка на клип трека на YouTube.

### Звук, который видно и чувствуется
- Анализатор сидит прямо в аудиопотоке (`MTAudioProcessingTap` + vDSP FFT) и привязан ко времени того, что слышно, а не того, что декодировано.
- Визуализатор на Metal: «Дым», «Дыхание», «Рельеф», «Сканер», «Матрица» (ASCII-эффекты из обложки).
- Детектор бочки по самым низким частотам с точностью около 3 мс. На него завязаны прыжки визуализатора, покачивание обложки, живой BPM и «тактильный бас»: телефон стучит в руку ровно на удар, вибрация планируется заранее.

### Библиотека и поиск
- «Мне нравится» с кэшем, плейлисты (создать, переименовать, удалить трек, приватность), закреплённое, пресейвы, история прослушиваний.
- Поиск с подсказками и историей. Обзор по жанрам и настроениям.
- Страницы артиста (слушатели за месяц, дискография, концерты, биография, похожие) и альбома (лайк, похожие, «ещё у артиста»).
- Подборки на главной: недавнее, «собрано для тебя», новинки, чарт.

### Другие устройства
- **Ynison**: видно, что играет на ПК или Станции; можно управлять ими как пультом или забрать воспроизведение на телефон.

### Мелочи
- Тактильная отдача по всему интерфейсу, от едва заметных щелчков до жёсткого удара на дизлайке.
- Акцент интерфейса берётся из обложки текущего трека (отключается).
- «Карточка трека»: постер 1080×1350 с обложкой и спектром момента для сторис.
- Виджеты на «Домой» и экран блокировки, кнопка «Моя волна» для Пункта управления.
- Диплинки `volna://`.

## Сборка

Проект собирается **без Mac**: на Windows через [xtool](https://github.com/xtool-org/xtool) в WSL (на Linux и macOS — так же, без WSL). Xcode не нужен, только его SDK.

### Один раз: окружение

```bash
# PowerShell (Windows)
wsl --install -d Ubuntu-24.04
```

Внутри Ubuntu:

```bash
sudo apt update && sudo apt install -y curl rsync libfuse2t64 usbmuxd

# Swift 6.4 через swiftly
curl -O "https://download.swift.org/swiftly/linux/swiftly-$(uname -m).tar.gz"
tar zxf "swiftly-$(uname -m).tar.gz" && ./swiftly init --quiet-shell-followup
. ~/.local/share/swiftly/env.sh

# xtool
curl -fL "https://github.com/xtool-org/xtool/releases/latest/download/xtool-$(uname -m).AppImage" -o xtool
chmod +x xtool && sudo mv xtool /usr/local/bin/
```

Скачай Xcode (`.xip`, нужен Apple ID) на [developer.apple.com/download](https://developer.apple.com/download/all/?q=Xcode) и установи из него SDK:

```bash
xtool sdk install /mnt/c/Users/<you>/Downloads/Xcode_27.2.xip
swift sdk list   # должен появиться darwin
```

### Собрать IPA

Сначала, один раз, модель для ползунка «голос». Скрипт скачивает [UVR MDX-Net Kim Vocal 2](https://github.com/TRvlvr/model_repo) и конвертирует её в Core ML. Лицензия на веса не указана, поэтому в репозитории их нет:

```bash
bash tools/convert_vocal_model.sh
```

Потом сама сборка:

```bash
bash build.sh
```

Скрипт копирует проект на файловую систему Linux (сборка с `/mnt/c` нестабильна), собирает release и кладёт `Volna.ipa` в `xtool/`. Поставить на телефон можно любым сайдлоадером: [iLoader](https://github.com/nab138/iloader), SideStore, AltStore. С бесплатным Apple ID подпись живёт 7 дней.

### Вход

Вход через Яндекс ID в WebView. OAuth-токен перехватывается из редиректа и хранится в Keychain. Можно вставить токен вручную.

## Как устроено

| Путь | Что |
|---|---|
| `Sources/Volna/API` | Клиент `api.music.yandex.net`, модели, ссылки на поток (подпись запросов, расшифровка lossless), Ynison, LRCLIB |
| `Sources/Volna/Auth` | Вход, сессия, Keychain |
| `Sources/Volna/Player` | Два AVPlayer для бесшовности и кроссфейда, rotor-сессии волны, аудиоперехват (EQ, нормализация, анализ, бочка), тексты |
| `Sources/Volna/Visual` | Metal-визуализатор (шейдеры компилируются на устройстве), тема из обложки, хаптика |
| `Sources/Volna/Views` | Экраны и компоненты |
| `Sources/VolnaWidget` | Виджеты |

Подробный план и что уже сделано — в [ROADMAP.md](ROADMAP.md).

**Ограничения сборки через xtool:** App Intents (Siri, Shortcuts) не собираются, потому что нет генератора метаданных; Metal-шейдеры компилируются в рантайме из исходника.
