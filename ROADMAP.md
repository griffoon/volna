# Волна — план

Идём сверху вниз. Каждый пункт — отдельный коммит. Отметки `[x]` ставятся по мере готовности.

## 1. Баги

- [x] **Наушники и звонки.** Если выдернуть наушники или музыку прервал звонок, AVPlayer встаёт на паузу, а приложение считает, что всё играет: кнопка, визуализатор и экран блокировки врут. Нужно следить за реальным состоянием плеера, за прерываниями и за сменой аудиовыхода.
- [x] **Недоступный трек ломает воспроизведение.** Если трек не отдаётся (нет прав, регион, удалён), вылезает алерт и музыка встаёт. Должен молча пропускаться с записью в лог `tx`, а алерт — только если подряд не играет ничего.
- [x] **Дубли треков в списках.** Когда трек встречается в плейлисте дважды, у строк дублируются ключи: строки прыгают, тап запускает не тот трек. Очередь тоже ищет трек по первому совпадению.
- [x] **«Мне нравится» грузится заново при каждом открытии** (3446 треков ≈ 18 запросов). Держать в памяти и докачивать только новое.
- [x] **Протухшие ссылки на поток.** После долгой паузы или сбоя загрузки ссылка может умереть. Перезапрашивать ссылку и продолжать с той же позиции.
- [x] **Пустой мини-плеер.** Плашка «Ничего не играет» висит над таббаром, даже когда ничего не запускали.
- [ ] Визуальные баги со скринов (пришлёт пользователь).

## 1.5. Экран «Волны» как у Яндекса (скрины пользователя)

- [x] Фон — мягкое светящееся облако-дым в цветах обложки (как в Яндексе), реагирует на музыку; ASCII-эффекты остаются выбором в настройках.
- [x] Заголовок «Моя волна» сменяется на имя исполнителя, когда трек играет.
- [x] Под заголовком маленькая обложка, под ней ряд: [дизлайк] [название трека в пилюле] [лайк] […], ниже [назад] [Play] [дальше]. Дизлайк на видном месте.

## 2. Быстрые и полезные

- [x] **Тактильная отдача** по всему приложению: от едва заметных щелчков до жёсткого удара на дизлайке.
- [x] **Лайк и дизлайк на экране блокировки** и в Пункте управления (`MPRemoteCommandCenter` like/dislike) — учить волну, не разблокируя телефон.
- [x] **История прослушиваний** (`music_history`): полка «недавно слушал» на главной и экран истории.
- [x] **Похожие треки** (`tracks/{id}/similar`) в меню трека.
- [x] **Управление плейлистами** (`users_playlists_*`): создать, переименовать, удалить трек, приватность.
- [x] **Продолжить последнюю волну** (`rotor/wave/last`) с теми же настройками.
- [x] **Запоминать, где остановился:** после перезапуска та же очередь и позиция.
- [x] **Поделиться треком:** ссылка на music.yandex.ru.

## 3. Побольше

- [x] **Эквалайзер** через тот же аудиоперехват, что и у визуализатора: 10 полос, пресеты.
- [x] **Выравнивание громкости** по данным Яндекса о громкости трека.
- [x] **Подсказки и история в поиске** (`search/suggest`).
- [x] **Кто сделал трек** (`credits`): авторы, продюсеры.
- [x] **Артист:** биография, полная дискография, концерты (`concerts`). Клипы — позже.
- [x] **Закреплённое** (`pins`) наверху «Коллекции», синхронно с официальным приложением.
- [ ] **Жанры и настроения** (`metatags`): раздел «Обзор».
- [ ] **Пресейвы** (`presaves`): будущие релизы любимых артистов.
- [ ] **Siri и Быстрые команды:** «Включи мою волну», «Любимое вперемешку».
- [ ] **Тактильный бас** (Core Haptics) — баловство, выключено по умолчанию.

## 4. Большое

- [ ] **Синхронизация между устройствами** (`queue` / Ynison): подхватить, что играло на ПК или Станции, пульт для других устройств. Отдельный протокол на websocket.
